# go-converter

Сервис и CLI для конвертации документов с гибким выбором целевого
формата. Go-обёртка над LibreOffice headless с асинхронной очередью
задач, HTTP и gRPC API.

Статус: в активной разработке.

## Идея

Загружаешь документ — получаешь файл в нужном формате. Работает в
двух режимах:

CLI — локальная конвертация одного файла (можно повесить на
  контекстное меню ОС)
Сервис — HTTP/gRPC API с очередью: загрузил → получил `job_id` →
  опрашиваешь статус → скачиваешь результат

Направление конвертации задаётся (параметром запроса), а не отдельной
ручкой. Основной, качественный сценарий — (из офисных форматов в PDF)
(docx, odt, xls, pptx → pdf), где LibreOffice силён. Обратное
направление (PDF → docx) поддерживается, но с ограничениями —
подробности в разделе «Обратная конвертация».

Конвертация выполняется через LibreOffice в headless-режиме внутри
Docker-контейнера. Go оркестрирует очередь, хранение и API.

## Стек

- Go — HTTP API, gRPC, воркеры, CLI
- PostgreSQL — очередь задач и метаданные
- Docker / docker-compose — Go-сервис + LibreOffice + Postgres
- LibreOffice headless — движок конвертации

## Обратная конвертация (PDF → docx)

PDF — это формат (финальной вёрстки), а не редактируемый документ:
внутри нет понятия «абзац» или «таблица», только команды рисования.
Поэтому PDF → docx — это обратная инженерия структуры по геометрии,
и результат (не будет идентичен оригиналу). Так работает любая
PDF→docx конвертация, включая Adobe.

Что это значит для проекта:

- docx → pdf — основной, качественный сценарий
- pdf → docx — бонусный, работает приемлемо для простых текстовых
  PDF, но таблицы и сложная вёрстка могут «поехать»
- сканы (PDF-картинки) — не поддерживаются, потребовали бы OCR
- PDF → txt/md — надёжная альтернатива, если нужен просто текст
